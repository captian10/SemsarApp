# SemsarApp 🏠

A real estate marketplace mobile application built with **React Native**, **Expo**, **TypeScript**, and **Supabase**.

The app allows users to browse property listings, view property details, manage saved listings, and interact with a clean mobile-first real estate interface.

---

## Features

- Browse property listings
- View property details with images
- Authentication flow
- Favorites / saved listings
- Clean reusable UI components
- Supabase backend integration
- Database, authentication, and storage-ready structure

---

## Tech Stack

- React Native
- Expo
- TypeScript
- Supabase Auth
- Supabase Database
- Supabase Storage
- Git & GitHub
